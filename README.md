# Data Apps

A repository for interactive data applications built with frameworks like **Shiny** (R) and **Streamlit** (Python). These apps accompany posts from my personal GitLab blog.

## Applications

### 1. A/B Test Sample Size Calculator (Shiny)
* **Directory:** [`shiny/sample-size`](./shiny/sample-size)
* **Live App:** [cbhyphen-sample-size.share.connect.posit.cloud](https://cbhyphen-sample-size.share.connect.posit.cloud/)
* **Description:** Calculates the required sample size and critical delta for A/B tests assuming a binomial distribution. Visualizes probability densities and Type I/II error regions across baseline conversion rate, minimum detectable effect, significance level, and statistical power.

### 2. Options Volatility Explorer (Streamlit)
* **Directory:** [`streamlit/options-volatility`](./streamlit/options-volatility)
* **Live App:** [cbhyphen-options-volatility.share.connect.posit.cloud](https://cbhyphen-options-volatility.share.connect.posit.cloud/)
* **Description:** Fetches live options chain data to visualize 2D volatility skew, option deltas by strike and expiration, and multi-window Volatility Risk Premium (VRP), alongside expiration-tabbed option chain tables.
